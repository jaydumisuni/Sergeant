## Final safe submission wording

```text
Sergeant is a model-free evidence-based engineering reviewer with CLI review, App Bridge handoff, IDE Bench contracts, permanent officers, battle-test benchmarks, verified learning, CI proof, clean-clone proof, production hardening, and release proof. It verifies claims against implementation and produces PASS / NEEDS WORK / BLOCK verdicts without requiring an AI-provider login, model API, or GPU. Owners may optionally enable one model or a bounded multi-model council for extra reasoning, but models are support engines rather than Sergeant's core or final authority. Secret detection is proven with planted positive and clean-control cases. GitHub PR ingestion is proven through both GitHub-shaped fixtures and a real read-only API workflow that captures sanitized request evidence without exposing comment bodies or credentials.
```

## Freeze rule

Do not claim that Sergeant requires a model, is defined by a multi-model council, writes GitHub reviews, automatically patches code, automatically promotes lessons, or executes pull-request-controlled code.

Do not weaken the secret-detection or live-ingestion claims; both are backed by explicit proof artifacts and regression tests.

## Hackathon use

Use Sergeant as a supporting trust layer for the hackathon submission:

- it improves the credibility of Hunter Foreman;
- it demonstrates proof-before-claim engineering;
- it shows the ecosystem has independent model-free review capability;
- it gives judges a reason to trust the submitted code and claims;
- optional model reasoning can be demonstrated as an extra mode rather than a dependency.
