# Sergeant 0.4.2 — Public Extension Reset

Sergeant 0.4.2 corrects the public IDE experience so the published product matches the proven architecture.

## What changed

- VS Code, Open VSX, JetBrains, Python metadata, and runtime version are coordinated at `0.4.2` / `0.4.2-preview`.
- Marketplace descriptions now identify Sergeant as a model-free engineering reviewer.
- The VS Code sidebar is reduced to focused review actions and the last report.
- The shared Review Center hides internal doctrine, roadmap, officer, writer, and debugging surfaces from the normal public flow.
- Optional model reasoning remains available in advanced settings but is disabled by default.
- Stale `0.4.0-preview`, provider-first, and free-model product language is removed from published runtime surfaces.
- The root README is shortened for marketplace use and links to advanced documentation instead of reproducing the whole internal architecture.

## Standard behavior

```text
Repository / changed files
→ model-free Cpl coordination
→ permanent officers and privates
→ deterministic evidence and verified lessons
→ Judge ledger
→ Sergeant verdict
```

No AI-provider login, hosted model, API key, or large GPU is required for normal review.

## Optional behavior

A user may explicitly enable one model or a bounded multi-model council for extra reasoning. That support remains subordinate evidence and never becomes Sergeant's identity or final authority.

## Upgrade

### Python

```bash
python -m pip install -U sergeant-reviewer==0.4.2
```

### VS Code / Open VSX

Update Sergeant to `0.4.2` through the extension manager.

### JetBrains

Update to `0.4.2-preview` in the preview channel.

Existing optional-model settings retain their stable storage keys, but the extension starts in model-free mode unless the user has deliberately enabled a route.

## Release boundary

This release contains the public-extension correction only. It does not automatically promote learning candidates, merge the paused cross-repository harvest, or grant writer/merge authority.
