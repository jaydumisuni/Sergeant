## Hostile-review repair (review of `005e5b684b7ae37ca129b86f9f78345e65e2342d`)

The earlier boundary trusted record fields and caller booleans. It now works as follows:

- **External evidence is re-verified.** Each `ExternalEvidenceProvenanceRecord` is re-derived through the canonical SAE-30 `ExternalEvidenceProvenanceRecord.create()` from its own fields, its `AuthenticatedProvenanceProof` (`external_evidence_proofs`) and a provenance verifier supplied outside the package (`trusted_provenance_verifiers`), following the SAE-30 `admit_qualification_attestation(registry=...)` trust-anchor pattern. A directly constructed record fails with `EXTERNAL_PROVENANCE_UNVERIFIED`; a verifier that is not trusted fails with `EXTERNAL_PROVENANCE_VERIFIER_UNROOTED`. Either way the record is conserved as `UNKNOWN_INDEPENDENCE`.
- **Lane cardinality is not candidate-authored.** Requirements come from ACR `ExternalReviewLane` values passed in as `ratified_external_review_lanes`, and never drop below the SPIKE-EXT floor (`docs/65`: 2 instances, 2 distinct source classes). Only the SPIKE-EXT source classes SC-1 to SC-4 and SC-6 count; SC-5 and free-text classes do not. SAE-20 never ratified a Genesis lane, so without a ratified lane the package is blocked with `GENESIS_LANE_CARDINALITY_UNRATIFIED`.
- **Obligations close only through admitted qualification.** Preservation, model-blackout, CPU, historical replay, clean controls, unrelated transfer, independently authored hidden cases, independent hostile implementation review and each of the eight mutation families close only through a canonical `QualificationAttestation`. That attestation must have been admitted (consumed, not revoked) in a trusted `QualificationAuthorityRegistry`, be issued by an active authorized issuer, and be bound to the exact Review World and the candidate, ACR and qualification-protocol generations. The two independent obligations also require `INDEPENDENT` qualification. Caller booleans carry no authority. A reported surviving required mutant blocks.
- **UNKNOWN is conserved.** Every residual UNKNOWN blocks (`MANDATORY_UNKNOWN`), because no qualified ACR classifies any UNKNOWN as non-mandatory. `UNKNOWN_INDEPENDENCE` evidence is added to the residual UNKNOWNs, and every record's disposition is reported.
- **The package has one identity.** The result carries a canonical SAE-30 `GenesisQualificationPackage` (still `GENESIS_PROVISIONAL`) and a digest over the whole package. Generation identities are validated: the candidate is a git object id, the RAB is a full SHA-256, and ACR/Rust/qualification-protocol generations are immutable canonical identifiers. Declared limitations are mandatory.
- **Prerequisite bindings are typed and checked against git.** Each binding is tagged as `commit` or `blob`. SPIKE-EXT is bound to {path, blob} anchored at base main, and the campaign test verifies it with `git rev-parse` and `git hash-object`.
